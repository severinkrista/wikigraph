# WikiGraph 2.0.0

Android-приложение для построения собственной исторической временной шкалы из статей русской Википедии.

## Возможности

- Отдельные режимы: поиск статей, каталог категорий и рекомендации — результаты одного режима не перекрывают другой.
- Каталог категорий с тематическими разделами, поиском по названию, просмотром подкатегорий и списком статей категории.
- Добавление нескольких статей на одну временную шкалу с локальным сохранением набора.
- Загрузка дат из полного текста статьи и связанных данных Викиданных; доступные даты можно выбирать.
- Подбор статей, связанных с исходной темой и выбранным историческим периодом.
- Быстрые интервалы рекомендаций: ±1, ±5 и ±10 лет от стартовой даты.
- Выбор стартовой статьи из уже добавленного набора; рекомендации учитывают совпадения годов в статье и категории исходной статьи.
- Просмотр людей, событий и других сущностей на общей шкале, карточки статьи и переход к оригиналу в Википедии.
- Масштабирование шкалы жестом двумя пальцами и перемещение по увеличенному диапазону.

## Как искать статьи по категории

1. Откройте вкладку **Поиск статей** и переключитесь на режим **Каталог категорий**.
2. Выберите тематический раздел (например, **История**, **Наука**, **География**) или введите название категории в поле поиска.
3. У каждой категории можно открыть **Подкатегории** либо нажать **Статьи**, чтобы увидеть её содержимое.
4. Добавляйте нужные статьи кнопкой «+». Для обычного поиска вернитесь в режим **Поиск статей**; он работает независимо от выбранных категорий.

## Как находить события вокруг темы

1. Найдите стартовую статью и добавьте её на шкалу.
2. Перейдите в режим **Рекомендации**. В списке выбранных статей можно нажать **Старт** напротив другой статьи.
3. Выберите интервал **±1 год**, **±5 лет** или **±10 лет** и нажмите **Найти рекомендации**.
4. Просмотрите предложенные статьи и добавьте подходящие кнопкой «+». Чтобы продолжить обычный поиск, просто переключитесь обратно на **Поиск статей**.

Рекомендации формируются по годам в выбранном диапазоне, вступлениям статей и категориям исходной статьи. Это подборка кандидатов, а не гарантированно полный список исторических событий: даты в Википедии могут быть упомянуты не в начале статьи, а часть материалов может не иметь корректно размеченных дат.

## Сборка APK

Откройте репозиторий в Android Studio, дождитесь синхронизации Gradle и выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Автоматическая сборка доступна во вкладке **Actions → Android APK**. После успешного выполнения workflow публикует APK-артефакт с версией в имени, например `wikigraph-2.0.0-debug.apk`. Версия приложения задаётся в `app/build.gradle.kts` параметрами `versionCode` и `versionName`.

Требования: JDK 17, Android SDK Platform 35, Gradle 8.9.

## Источники и ограничения

- Поиск и категории: MediaWiki API русской Википедии.
- Даты и свойства сущностей: Wikidata и текст статьи Википедии.
- Для работы нужен интернет.
- Качество дат зависит от содержимого статей и заполненности Викиданных. Автоматический разбор текста может пропустить нестандартно записанную дату или распознать год, не относящийся к основному событию.
