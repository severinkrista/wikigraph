# WikiGraph

Android-приложение для сборки собственной исторической временной шкалы из статей Википедии.

## Что уже работает

- Поиск статей в русской Википедии.
- Добавление сущностей на личную шкалу и локальное сохранение списка между запусками.
- Загрузка дат и описания из Викиданных по связанному элементу Википедии.
- Отображение людей, событий и сущностей на общей шкале; фильтры по типу.
- Мини-обзор временного диапазона, отдельная карточка сущности и переход к статье.
- Сборка debug APK через GitHub Actions.

## Интерфейс и развитие

Основной экран сочетает поиск, фильтры и шкалу. Длинные интервалы показываются полосой, даты-точки — маркерами. Дальнейшие этапы: интерактивное масштабирование и прокрутка по оси времени, редактирование неточных дат, подборки, синхронизация и более точная классификация событий/эпох.

## Сборка

Откройте репозиторий в Android Studio и дождитесь синхронизации Gradle, затем выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Или запустите workflow **Android APK** на GitHub (вкладка Actions). Успешная сборка публикует артефакт `wikigraph-debug-apk`, содержащий `app-debug.apk`.

Требования: JDK 17, Android SDK Platform 35, Gradle 8.9.

## Источники и ограничения

Поиск выполняется через MediaWiki API русской Википедии, даты — через Викиданные. Запросы требуют интернет-соединения. Заполненность и точность дат зависят от данных Wikidata; не у каждой статьи есть подходящие свойства дат. В первой версии временная шкала отображается в виде сортированного списка и мини-обзора, а не полноценного масштабируемого графического полотна.
